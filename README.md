# Ghost Optimizer

Ghost Optimizer — это продвинутый скрипт с открытым исходным кодом, который повышает производительность ПК, снижает задержки, оптимизирует сеть и приватность, удаляя ненужный софт и функции ИИ.

## Особенности
- Интерактивный TUI (Text User Interface)
- Интеграция с системными утилитами Windows
- Оптимизация сети, устройств и ОС

## Требования
- Python 3.6+
- (Опционально) Запуск от имени Администратора на Windows для полного функционала

## Запуск
```bash
python ghost_optimizer.py
```

## Предупреждение
Опция отката твиков может работать нестабильно. Создайте точку восстановления системы перед использованием. Используйте на свой страх и риск.
